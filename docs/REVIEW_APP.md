# 100投稿の画像確認ツール

リポジトリ直下の `確認ツールを開く.cmd` をダブルクリックするか、`python -m pipeline.review_app --open` を実行します。Python標準ライブラリだけを使用し、127.0.0.1で動作します。現在のPCの実行データと分割ZIPを読み、画像・ラベルを外部へアップロードしません。

画像とTerraの判定を左右に表示します。複数画像は画像下のサムネイルで切り替え、画像を押すと拡大できます。左の「ランダムに10投稿だけ見る」で少数から確認できます。すべての投稿の確認は必須ではありません。

- 「合ってそう」「気になる」「保留」で確認結果を保存します。左右キーで投稿移動、1・2・3でも判定できます。
- 気になる項目の旗を押すと項目を記録し、未確認なら「気になる」に変わります。旗の解除だけで「合ってそう」には変えません。
- メモは任意です。判定後に移動したくない場合は「判定したら次へ」を外します。
- 確認結果は `private/reviews/pilot-v3-001.json` に自動保存します。「確認結果をダウンロード」でJSONのコピーを保存できます。元のAIラベルやGitのジョブ状態は変更しません。
- `displayed_media` は画面に表示した画像の記録で、人が画像を精査した証明ではありません。AIの判定を見ながらの簡易確認として保存し、独立した盲検評価とは区別します。

新ルールの既定runは `pilot-v3-001`、ポートは8766です。入力は `.runtime/recovered/pilot-v3-001` の完成結果と、除外適用済み `dist/data-v3-7113eaaefc38` の2本のZIPです。起動時にハッシュ・対応・schema・除外ポリシーを検査します。画像キャッシュと人手確認はrun別に保存し、旧回答は上書きしません。画像・人手確認結果はGitの追跡対象外です。

主題、制作方法、色、背景の描き込み、投稿全体のキャラクターと画像別の髪色を表示します。ポリシー拒否で暫定除外された投稿と同一ハッシュ画像は表示経路から外し、件数のみ示します。画像の保存内容が変更されていた場合も表示を拒否します。

旧版は `python -m pipeline.review_app --config runs/pilot-v2-001.json --port 8765 --open` で開けます。旧版は旧ルールと明記されます。

同じ確認結果を複数画面から編集し、競合した場合は上書きせず保存エラーを表示します。サーバーを停止した場合も保存済みの確認結果は残ります。
