# イラスト卒論の分類データ

**既存の卒論分析を再現する場合は、固定版 `fixed-11543` を使ってください。** データはコミット単位で固定しています。

| 版 | 含まれる記録 |
| --- | --- |
| [固定版のマニフェスト](https://github.com/ugin-man/x-illustration-labeling/blob/28af267de6609abf09ebaf7f64add48e2dede233/fixed-11543/manifest.json) | 2026年11月14日時点の11,543処理記録。分類ラベル11,512件、ポリシー暫定除外31件。 |
| [追加版のマニフェスト](https://github.com/ugin-man/x-illustration-labeling/blob/28af267de6609abf09ebaf7f64add48e2dede233/additions-20261124/manifest.json) | 2026年11月24日版の追加ラベル842件。別経路のKoyo回収117件、Hydrogen試行50件、Hydrogen継続作業675件。固定版との投稿ID重複は0件。 |

[データの読み出し手順](https://github.com/ugin-man/x-illustration-labeling/tree/28af267de6609abf09ebaf7f64add48e2dede233)には、固定版・追加版・明示的に両方を選ぶ方法があります。既存分析の再現は固定版から始めてください。ポリシー暫定除外と回収時の未確定記録は、分類ラベルと区別します。
