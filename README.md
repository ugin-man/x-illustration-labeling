# イラスト卒論の分類データ

**既存の卒論分析を再現する場合は、固定版 `fixed-11543` を使ってください。** 各版はコミット単位で固定しています。

| 版 | 含まれる記録 |
| --- | --- |
| [固定版](https://github.com/ugin-man/x-illustration-labeling/tree/28af267de6609abf09ebaf7f64add48e2dede233/fixed-11543) | 11,543処理記録（分類ラベル11,512件、ポリシー暫定除外31件） |
| [最新追加版・11月26日](https://github.com/ugin-man/x-illustration-labeling/tree/f8ba35b2534734988dc40a2a85ca08f08db5fa84/additions-20261126) | 追加ラベル2,048件（前回842件、今回のHydrogen分1,206件）。11月26日13:22 JST締め。固定版との投稿ID重複は0件。 |
| [前回の追加版・11月24日](https://github.com/ugin-man/x-illustration-labeling/tree/28af267de6609abf09ebaf7f64add48e2dede233/additions-20261124) | 追加ラベル842件。前回版での再現に使えます。 |

11月26日版は11月24日版の842件を含みます。追加ラベルを使う場合は、対象とする追加版を一つ選んでください。

[データの読み出し手順](https://github.com/ugin-man/x-illustration-labeling/tree/f8ba35b2534734988dc40a2a85ca08f08db5fa84)から、固定版、最新追加版、または両方を選んで出力できます。分類ラベルとポリシー暫定除外は別のファイルに出力されます。
